# 🗺️ Side Quest

### Group plans, decided.

Side Quest is a group planning app for finding affordable, fun things to do in NYC without the endless group-chat debate.

Instead of sending a dozen suggestions and waiting for everyone to agree, a group can create a room, set their preferences, and swipe through personalized recommendations together. When everyone likes the same option, Side Quest finds the match.

## 💡 The Problem

Planning a spontaneous outing with friends can be surprisingly difficult.

People have different:

* Budgets
* Schedules
* Locations
* Interests
* Preferences

This becomes especially difficult in a city like NYC, where friends may live in different neighborhoods or residence halls and there are thousands of possible things to do.

## 🚀 Our Solution

Side Quest combines **personalized NYC discovery** with **group decision-making**.

A group can:

1. Set a budget, time limit, location, and vibe
2. Create a shared room
3. Invite friends using a room code
4. Swipe through recommended activities and venues
5. Find mutual matches
6. Go on their Side Quest 🎉

## 🎯 Initial MVP

Our first version will focus on:

* Group rooms with unique room codes
* Real-time group participation
* Swipe-based recommendations
* Matching based on group preferences
* NYC recommendations filtered by budget, time, location, and category
